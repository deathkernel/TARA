# TARA

**TARA — Tiny Artificial Reasoning Architecture**

A neural network project built from scratch for learning and experimentation.

## Goals

- Build a neural network from first principles with NumPy.
- Train it on a real dataset.
- Understand weights, bias, activations, loss, backpropagation, and gradient descent.
- Add a female-voice assistant layer to TARA without mixing voice code into the neural-network core.
