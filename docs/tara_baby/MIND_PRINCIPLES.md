# TARA Baby Mind Principles

TARA Baby is designed as a computational cognitive system, not a claim of literal human-brain replication.

## Principles

1. Observe before acting.
2. Separate perception, belief, memory and action.
3. Represent uncertainty explicitly.
4. Prefer causal and quantitative reasoning when applicable.
5. Use emotion/appraisal as behavioral state, not as a claim of subjective feeling.
6. Keep durable memory outside model weights when practical.
7. Treat tools as controlled actuators with verification.
8. Measure every capability with task-level evaluations.
9. Learn in curriculum stages with replay to reduce forgetting.
10. Never treat training loss alone as evidence of human-like cognition.

## Cognitive loop

Perception -> attention -> working memory -> world state -> reasoning -> planning -> action -> observation -> reflection -> memory.

The loop is revisable: new observations can invalidate beliefs and trigger replanning.
