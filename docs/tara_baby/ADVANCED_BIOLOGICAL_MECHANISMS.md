# Advanced Biological Mechanisms

## Global workspace

Global-workspace theories propose that selected information can become broadly available to multiple specialized systems. TARA adopts only the functional part of this idea: a small broadcast workspace that makes selected representations available to cognition modules. This is not a claim that TARA is conscious. citeturn716457search10

## Neuromodulatory control

Neuromodulatory biology can change learning and behavioral state. Recent 2026 work on dopamine-linked learning emphasizes that learning dynamics depend on reward timing, challenging overly simple fixed trial-by-trial learning-rate assumptions. TARA therefore keeps learning gain as an explicit state signal rather than hard-coding one universal rate. citeturn716457search11

## Closed-loop scientific learning

Closed-loop neuroscience uses active learning to select informative observations that refine a working model. TARA's scientific-reasoning layer can now choose experiments by expected Bayesian information gain per cost. citeturn716457search2

## Connection to the existing loop

`attention -> global workspace -> working memory -> world model -> prediction -> appraisal -> scientific reasoning -> metacognition -> active experiment/planning -> executive gate -> action -> observation -> reflection -> replay -> consolidation`

This creates an explicit information-selection and learning-control pathway while preserving the project's rule that each mechanism must remain independently testable.
